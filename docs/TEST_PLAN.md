# Test plan

Honest status is recorded in the final section after each run. "Verified" means
the test ran and passed in this repository; "requires key" means it only runs
with `OPENAI_API_KEY` present and has not been run otherwise.

## Layers

| Layer | Tool | Command | Database |
|---|---|---|---|
| Unit | vitest | `npm run test:unit` | none (mocks) |
| Integration | vitest | `npm run test:integration` | `companion_test` (real Postgres) |
| End-to-end | Playwright + Chromium | `npm run test:e2e` | `companion_test` via `next start` |
| Static | tsc, eslint | `npm run typecheck && npm run lint` | — |
| Live acceptance | `npm run verify` + `tests/e2e/live.spec.ts` | requires `OPENAI_API_KEY` | — |

Chromium runs with a **fake microphone** (`--use-fake-device-for-media-stream`
and `--use-file-for-fake-audio-capture=tests/fixtures/fake-mic.wav`, a
speech-like signal generated by `tests/fixtures/make-fake-mic.py`), so orb
amplitude and VAD can be exercised without a human.

## Acceptance tests (AGENTS.md) → where they are checked

| # | Acceptance test | How it is checked |
|---|---|---|
| 1 | Real two-way voice conversation | `live.spec.ts` (requires key): mint session, WebRTC connects, data channel opens, assistant transcript arrives after fake-mic speech. Demo path: `talk.spec.ts`. |
| 2 | Orb responds to mic and assistant audio | `orb.spec.ts`: `data-mic-level` rises during fake-mic speech bursts and falls in silence; `data-output-level` rises while assistant speaks (live) / synthetic level (demo). Unit: `useAudioLevel` math. |
| 3 | Interrupt stops assistant promptly | Unit: adapter sends `response.cancel` + `output_audio_buffer.clear` on `speech_started` while speaking; reducer enters `interrupted`. Live: `live.spec.ts` measures time from barge-in to `output_audio_buffer.cleared`. |
| 4 | Pauses don't cause premature cut-off | Session config uses `semantic_vad` with `eagerness: low` for "patient" (unit test). Live: fake-mic file has a 2 s mid-utterance pause; test asserts one user turn, not two. |
| 5 | Consent → fact saved → recalled next session | Integration: `memory.test.ts`; e2e `memory.spec.ts` (demo): say "remember that…", end, start new session, assistant references it / memory page lists it. |
| 6 | Model switch preserves app-owned context | Unit: `buildMemoryContext` with `continueConversationId` includes recent transcript; e2e `talk.spec.ts` switch mid-conversation shows the switch note and continues the same conversation. |
| 7 | Inspect/correct/delete; deleted facts stay deleted | Integration: tombstone + summary suppression + re-save rejection; e2e `memory.spec.ts`. |
| 8 | Humor level changes behavior; serious topics serious | Unit: instructions contain level-specific rules; demo brain tests (serious keywords drop humor). Live: manual script in `PREVIEW.md`. |
| 9 | Respectful disagreement | Unit: instructions include disagreement rules; demo brain corrects listed falsehoods. Live: manual script. |
| 10 | Secrets not in browser; isolation | `scripts/check-secrets.sh` greps `.next/static`; integration `isolation.test.ts`. |
| 11 | Demo works without key; live works with key | e2e demo suite runs with no key; `npm run verify` + `live.spec.ts` with key. |
| 12 | Usage and cost visible | e2e `developer.spec.ts`; unit pricing tests. |
| 13 | Local launch reproducible; preview claims verified | `README.md` steps executed in a clean shell; `PREVIEW.md`. |
| 14 | Tests pass or failures reported | Final section below. |
